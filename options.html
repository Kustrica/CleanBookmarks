Icon-only bookmarks

Bookmarks whose title is empty or just repeats the address get an invisible title, so only the favicon is shown. Bookmarks with real names are never changed.

Before

MMDN Web Docs
Y(no title)
Ghttps://www.github.com/

After

MMDN Web Docskept
Yicon only
Gicon only
Ghttps://www.github.com/kept

Matches the address with or without https://, www. or a trailing slash. Turn off to hide only empty titles.

A bookmark is checked as soon as you create it or change its title.

Also runs once after the extension is installed or updated.

“Hide now” checks all bookmarks with the rules above. “Restore titles” gives icon-only bookmarks a visible title again – the site address, for example github.com/Kustrica.

Quick add

Save the current tab from the bookmark context menu – on the bookmarks toolbar, in the Bookmarks menu or in the sidebar.

Right-click a folder to save the current tab into it, or right-click a bookmark to save the tab right after it.

Where to put it in a folder

The bookmark is saved without a visible title, so only its favicon is shown – handy for a compact toolbar of site icons.
